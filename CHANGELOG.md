# Changelog

## 0.1.0 — 2026-11-05

First public release.

- `packages/seal-check`: PDF scanner (signature objects, flat pages, reused bitmaps, producer and dates, generator page sizes), `sealVerdict`, `crossFileReuse`, three synthetic fixtures, tests.
- `packages/interview-dsl`: step types, `nextStepId`, `path`, `step`, an example interview, tests.
- `tools/wrangler-d1-migrate-retry`: retry wrapper for `wrangler d1 migrations apply`.
- `docs/lead-referral-consent.md`: consent and disclosure wording template.
- `docs/principles.md`: the "model never decides money" rule.
